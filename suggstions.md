# Simple server suggestions

- **Admin health screen:** one command showing database health, pending saves, slow systems, and unresolved dupe cases.

- **New-player checklist:** a small GUI pointing players to kits, factions, mines, /events, and the first useful commands.

- **Faction missions:** short daily mining, farming, defending, and objective goals with faction-wide rewards.

- **Scheduled war events:** a short timed PvP event with a clear countdown, rules, participation reward, and winner reward.

- **Admin transaction search:** one staff screen for a player's GC, auction, coinflip, faction-bank, and dupe history.

- **Season dashboard:** show reset date, active boosters, top factions, next events, and live server goals in one polished GUI.

- **Recovery drills:** a staging-only command that safely simulates a failed transaction so restart recovery is tested before launch.
